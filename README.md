# Student Registration System

# GitHub Repository

# Project Overview
The Student Registration System is a web-based application developed using HTML, CSS, and JavaScript.  
It allows users to register student details, view records, edit existing entries, and delete records dynamically using JavaScript DOM manipulation.

The application uses Local Storage to store data, ensuring that student records are not lost even after refreshing the page.

# Features
- Include a catchy title reflecting the system's purpose
- Register new student details
- Edit existing student records
- Delete student records
- Input field validation
- Include a section to display registered student records
- Make sure the user can't add the empty row
- Add a vertical scrollbar dynamically.
- Dynamic vertical scrollbar using JavaScript
- Data persistence using Local Storage
- Fully responsive design (Mobile, Tablet, Desktop)

# Technologies Used
- HTML – Structure of the application
- CSS – Styling and responsive design
- JavaScript – DOM manipulation, validation, and Local Storage

# Project Structure

# Validation Rules Implemented
- Student Name: Only alphabets and spaces are allowed
- Student ID: Only numeric values are allowed
- Email ID: Must be a valid email format
- Contact Number: Only numbers allowed, minimum 10 digits
- Empty fields are not allowed

# Responsive Design
The application is fully responsive and adapts to different screen sizes:
- Mobile devices : (≤ 640px)
- Tablet devices : (641px – 1024px)
- Desktop screens: (≥ 1025px)

# Local Storage
All student records are stored using the browser’s Local Storage, ensuring data remains available even after page refresh or browser restart.

# How to Run the Project
1. Download or clone the repository
2. Open the index.html file in any modern web browser
3. Start registering student details
